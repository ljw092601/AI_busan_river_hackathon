# 시연 대본 — 부산 하천 탐험대

> 이 문서에 적힌 화면과 흐름은 **2026-08-14 기준 배포본에서 실제로 확인한 것**만 담았습니다.
> 확인하지 못한 기능은 §5에 따로 모아 두었고, 대본에는 넣지 않았습니다.

**배포 URL — 반드시 이 주소로 시연하세요**

```
https://ai-busan-river-hackathon.vercel.app/?demo=1
```

`?demo=1` 을 붙이면 우하단에 `🧪 시연 도구` 버튼이 생깁니다. 이 버튼이 **대본 전체의 핵심 장치**입니다.
현장에 가지 않고도 5개 하천 중 아무 곳으로나 위치를 옮겨 잠금해제를 보여줄 수 있습니다.

> **Vercel 프리뷰 URL(`*-git-*.vercel.app`, `*-abc123.vercel.app`)로는 시연하지 마세요.**
> 카카오 지도 앱 키는 콘솔에 등록한 도메인에서만 동작하고, 프리뷰 URL은 배포마다 주소가 바뀌어
> 등록이 불가능합니다. 프리뷰에서는 **지도가 100% 실패합니다.** 프로덕션 도메인에서만 뜹니다.

### 주소와 화면

- [ ] 주소창이 **정확히** `https://ai-busan-river-hackathon.vercel.app/?demo=1` 인가
      (프리뷰 URL 아님 · `http://` 아님 · localhost 아님)
- [ ] **강력 새로고침** 했는가 — `Ctrl+Shift+R` (Mac `Cmd+Shift+R`)
      이 앱은 PWA라 서비스워커가 옛 화면을 캐시합니다. 일반 새로고침으로는 안 바뀝니다
- [ ] 우하단에 `🧪 시연 도구` 버튼이 보이는가 — 안 보이면 `?demo=1` 이 빠진 것입니다
- [ ] 화면 중앙에 **카카오 지도**가 떴고 하천 핀 5개와 파란 점선 원이 보이는가
- [ ] 브라우저 확대/축소가 100%인가, 발표용 창 크기로 맞춰 뒀는가

### 네트워크

- [ ] **행사장 와이파이 말고 휴대폰 테더링**을 준비해 두었는가 (전환 방법을 미리 눌러 보기)

- [ ] 시연 직전에 페이지를 한 번 열어 지도까지 떠 있는 상태로 두었는가 (SDK가 캐시됩니다)

- [ ] **미리 로그인해 둔 계정**이 준비돼 있는가 — 3분 대본은 로그인 상태에서 시작합니다

      꼭 배포해야 한다면 §5를 읽고 처음부터 다시 리허설하세요.

### 휴대폰 미러링 (카메라 미션을 시연할 때)

카메라는 데스크톱 브라우저에서 열리지 않습니다(파일 선택창만 뜸). 실기기가 필요합니다.

- [ ] 안드로이드 **USB 디버깅** 켜짐 (설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7번 탭 → 개발자 옵션)
- [ ] USB 케이블 연결 후 휴대폰의 **"이 컴퓨터에서 항상 허용"** 체크 (무대에서 이 창이 다시 뜨면 곤란합니다)
- [ ] `adb devices` 에 `device` 로 표시되는가
- [ ] `scrcpy --stay-awake --max-size 900 --turn-screen-off` 로 창이 뜨는가
      (`--turn-screen-off` 를 쓰면 노트북에서 마우스로 조작할 수 있어 고개를 숙이지 않아도 됩니다)
- [ ] **휴대폰이 로그인 상태인가** ← 미로그인이면 수달을 눌러도 카메라가 열리지 않고
      "사진을 저장하려면 로그인이 필요해요" 안내만 뜹니다
- [ ] 백업 영상 준비 — scrcpy 창을 그대로 화면 녹화해 두세요

> 미러링은 USB 케이블이라 **현장 와이파이와 무관**합니다. 앱 자체는 인터넷이 필요하지만
> 그건 휴대폰 LTE 로 처리되므로 실패 지점이 분리됩니다.

## 4. 10분 버전 — 설계 근거까지

5분 버전에 아래 세 구간을 끼워 넣습니다.

### 4-A. 두 번째 하천으로 "확장성" 보여주기 (약 1분 30초) — 5분 대본 3:20 자리

`🧪 시연 도구` → **동천** → 카드 클릭 → 쓰레기 `🥤 🛍️ 🥫` 세 개를 차례로 클릭.

- 화면: "주운 개수 0/3 → 3/3", `🧹 쓰레기 3개 수거 완료!`, 곧바로 배지 (동천은 퀴즈가 0문항)
- 말: **"하천마다 미션 종류가 다릅니다. 그런데 코드가 하천마다 있는 게 아니에요.**
  미션 종류는 DB의 `mission_kind` 컬럼 한 칸이고, 세부 설정은 JSON 한 덩어리입니다.
  **6번째 하천을 추가하는 일은 코드 수정이 아니라 DB에 행 하나 넣는 일입니다.**
  동천은 퀴즈가 아예 없는데, 그것도 누락이 아니라 확정된 구성이에요 —
  **'없는 단계는 통과'** 라는 규칙이 서버에 들어 있습니다."

### 4-B. 서버가 다시 검사한다 (약 2분) — 배지를 받은 직후

> 화면 전환 없이 **말로** 하는 구간입니다. 굳이 코드를 띄우지 마세요. 띄운다면 발표자료(`presentation/deck.html`)의 해당 장으로만.

- "아까 잠금이 클라이언트 판정이라 우회할 수 있다고 말씀드렸죠. 그래서 **우회해도 소용없는 지점**을 따로 만들었습니다."
- "포인트 원장, 도감, 방문 기록 — 이 세 테이블은 **브라우저가 INSERT 자체를 못 합니다.**
  RLS로 봉인돼 있고, 오직 서버 함수만 기록합니다. 방금도 확인했는데 `permission denied` 가 납니다."
- "배지도 마찬가지입니다. `claim_river_badge` 는 **누가 요청했는지를 인자로 받지 않습니다** —
  로그인 토큰에서만 신원을 얻어요. 그리고 미션 기록과 정답 퀴즈 개수를 **서버에서 다시 세서** 조건이 안 맞으면 거절합니다."
- "포인트를 잔액 컬럼이 아니라 **원장(ledger)**으로 둔 것도 같은 이유예요. 원장은 수정·삭제가 막혀 있어서
  '이 포인트가 왜 생겼는지'를 항상 되짚을 수 있습니다. 회계가 수백 년째 이 방식을 쓰는 데는 이유가 있죠."

### 4-C. 정직한 한계 (약 1분 30초) — 마지막

이 구간을 빼지 마세요. **심사위원은 과장을 잡아냅니다.** 먼저 말하면 질문이 아니라 신뢰가 됩니다.

발표자료 "아직 사실이 아닌 것들" 장을 띄우고 그대로 읽습니다.

1. **하천 좌표는 미검증 근사값**입니다. 현장 답사를 하지 않았고, 하천은 선인데 점 하나 + 반경 1~1.5km로 근사했습니다
2. **AI 종 판별은 배포된 적이 없습니다.** 코드는 있지만 한 번도 실행되지 않았습니다
3. **카메라 미션은 리허설 전까지 실기기에서 검증된 적이 없었습니다** — 오늘 보신 것이 사실상 첫 실전입니다

## 5. 실패 대비 — 무슨 일이 나면 무슨 말을 하고 어디로 가는가

**공통 원칙 세 가지**

1. **당황해서 침묵하지 마세요.** 무슨 일이 났는지 한 문장으로 말하면 사고가 아니라 설명이 됩니다.
2. **같은 것을 두 번 이상 재시도하지 마세요.** 한 번 실패하면 바로 우회로로 갑니다.
3. 이 앱은 **모든 실패에 우회로가 설계돼 있습니다.** 그 사실 자체가 보여줄 거리입니다.

### 5-1. 지도가 안 뜬다 (도메인 미등록 · 광고 차단 · 네트워크)

**화면:** 지도 자리에 `🗺️ 지도를 표시하지 못했어요` + 원인 설명 + `다시 시도` 버튼
+ 회색 작은 글씨 **"지도가 없어도 아래 하천 목록과 미션은 그대로 쓸 수 있어요"**

**할 말:**
> "지도가 안 뜨네요. 원인은 대개 카카오 개발자 콘솔의 **도메인 등록**입니다.
> 그런데 보시면 — **에러 메시지가 원인과 해결 방법을 그대로 말해 주고 있고, 앱은 죽지 않았습니다.**
> 지도는 '있으면 좋은 것'이고 하천 목록과 미션이 본체라서, 실패를 이 상자 안에 가둬 뒀어요.
> 그대로 아래로 내려가겠습니다."

**우회:** 지도를 **완전히 무시하고** 아래 하천 카드로 내려갑니다. 시연 도구 → 하천 선택 → 카드 열림은
지도와 **무관하게** 동작합니다. 대본의 나머지 100%가 그대로 진행됩니다.

**하지 말 것:** `다시 시도`를 세 번 이상 누르기. 도메인 문제면 눌러도 절대 안 됩니다.

### 5-2. 위치 권한이 거부됐다

**화면:** "위치 권한이 거부되어 있어요. 브라우저 주소창의 자물쇠 아이콘에서…"

**이 상황은 대본에 영향이 없습니다.** 3·5·10분 대본은 **실제 GPS를 한 번도 쓰지 않습니다.**
`🧪 시연 도구`로 설정한 위치가 실제 GPS를 **덮어씁니다.**

**할 말:**
> "위치 권한이 막혀 있는데, 오늘 시연은 원래 시뮬레이션 위치로 진행합니다.
> 실제로는 이 자리에서 온천천까지 걸어갈 수가 없으니까요."

**주의:** 무대에서 `가까운 하천 찾기` 나 `내 위치 켜기` 를 **누르지 마세요.**
권한 팝업이 뜨고, 실내 wifi 측위는 오차가 수백 m라 엉뚱한 거리가 나올 수 있습니다.
시연 도구만 쓰면 이 위험이 통째로 사라집니다.

### 5-3. 네트워크가 끊겼다

**증상별 대응:**

| 증상 | 대응 |
|---|---|
| 페이지가 아예 안 열림 | **테더링으로 전환.** 전환 방법을 미리 눌러 봐 두는 것이 사전 점검 항목입니다 |
| 하천 목록이 안 나옴 (`📡 하천 정보를 불러오지 못했어요`) | `다시 시도` 한 번 → 안 되면 테더링 |
| 하천은 나오는데 위쪽에 노란 띠 `진행 상황을 불러오지 못했어요` | **그냥 진행하세요.** 이건 이미 설계된 부분 실패입니다 |
| 미션/퀴즈를 눌렀는데 빨간 `⚠️ 저장에 실패했어요` | **화면은 이미 완료로 바뀌어 있습니다.** 그대로 설명을 이어가세요 |

**할 말 (마지막 두 경우):**
> "저장이 실패했다고 나오는데, **화면은 그대로 진행됐습니다.** 이건 의도한 동작이에요.
> 하천변은 통신이 자주 끊기는데, 서버 응답을 기다렸다가 화면을 그리면
> 아이는 버튼을 눌러도 아무 반응이 없는 구간을 겪게 됩니다.
> 그래서 **화면은 즉시 반응하고, 저장 실패는 정직하게 따로 알려줍니다.**"

**최후의 수단:** 네트워크가 완전히 죽으면 **발표자료(`presentation/deck.html`)만으로 진행**하세요.
로컬 파일이라 인터넷 없이 열립니다. "라이브 시연은 끝나고 개별적으로 보여드리겠습니다"가
무대에서 3분간 새로고침하는 것보다 훨씬 낫습니다.

### 5-4. 로그인이 안 된다

| 화면에 뜨는 것 | 원인 | 무대에서 할 일 |
|---|---|---|
| "이미 가입된 이메일이에요" | 그 주소로 이미 가입함 | 화면이 **자동으로 로그인 모드로 바뀝니다.** 비밀번호만 넣으세요 |
| "이메일 또는 비밀번호가 올바르지 않아요" | 오타 / 다른 비밀번호 | **한 번만** 다시. 실패하면 §5-4 우회로 |
| "메일함을 확인해 주세요" | 프로젝트에 이메일 확인이 켜짐 | **여기서 멈추세요.** 메일함을 무대에서 열지 마세요 → 우회로 |
| 크롬 "비밀번호가 유출되었습니다" 빨간 팝업 | 흔한 비밀번호를 씀 | 팝업을 즉시 닫고 진행. 사전 점검에서 막을 수 있는 유일한 항목입니다 |

**우회로 (로그인을 포기하는 법):**
> "로그인이 말썽이네요. **로그인 없이도 앱은 전부 동작합니다** — 원래 그렇게 설계했어요.
> 기록이 저장되지 않을 뿐이고, 화면도 그렇게 말해 주고 있습니다."

그리고 **로그아웃 상태 그대로 3분 대본을 진행하세요.** 잃는 것은 배지 획득 연출 하나뿐입니다.
미션·퀴즈·해설·잠금해제는 미로그인에서도 **완전히 동일하게** 동작합니다.
배지는 이렇게 넘기세요: "여기서 로그인돼 있었다면 배지가 나옵니다. 서버가 조건을 다시 검사한 뒤에요."

### 5-5. 카메라가 안 열린다

**현재 배포본에는 카메라를 여는 화면이 없습니다.** 확인했습니다 — 배포된 번들에 사진 파이프라인이 들어 있지 않습니다.
따라서 **정상적으로 시연하면 이 상황은 발생하지 않습니다.**

이 항목이 문제가 되는 경우는 딱 하나입니다: **시연 전에 새로 배포했을 때.**
로컬에는 온천천·대천천 미션을 카메라 흐름으로 바꾸는 작업이 커밋되지 않은 채 남아 있습니다.
그게 배포되면 **로그인 상태에서** 수달을 누르는 순간 파일/카메라 선택창이 열리고,
**취소하면 미션이 완료되지 않습니다.**

**그 상황에서 할 일:**

1. 선택창이 열렸다면 → **아무 이미지나 하나 고르세요.** 취소하면 미션이 진행되지 않습니다
2. 실패해서 노란 상자가 떴다면 → **`사진 없이 완료하기`** 버튼을 누르세요. 반드시 함께 나옵니다
   - 할 말: "사진이 실패해도 미션을 막지 않게 해 뒀습니다. **하천까지 걸어간 아이를 카메라 권한 때문에
     미션 앞에 세워 둘 수는 없으니까요.** 실패에는 항상 빠져나갈 길을 같이 줍니다."
3. 그래도 막히면 → 모달을 닫고 **동천(쓰레기 줍기)** 으로 갈아타세요. 동천은 사진 단계가 없습니다

**가장 확실한 대비는 배포 동결입니다.** §1 마지막 항목.

### 5-6. 시연 도구 버튼이 안 보인다

1. 주소에 `?demo=1` 이 있는지 확인
2. 없으면 주소창 끝에 `?demo=1` 을 붙이고 Enter (한 번 붙이면 그 탭에서 계속 유지됩니다)
3. 그래도 없으면 **강력 새로고침** (`Ctrl+Shift+R`) — 서비스워커가 옛 번들을 물고 있는 경우입니다

이건 시연 5분 전에 반드시 눈으로 확인해야 하는 항목입니다. 무대에서 처음 발견하면 늦습니다.

### 5-7. 배지가 안 나온다

가장 흔한 원인은 **그 계정이 이미 그 하천의 배지를 가지고 있는 것**입니다.
그러면 완수 문구는 뜨지만 `🏅 이미 받은 배지예요.` 로 나옵니다.

- **대응:** 다른 하천으로 갈아타세요. 시연 도구로 즉시 이동하면 됩니다
- **예방:** 사전 점검의 "배지를 안 받은 하천 2개 이상" 항목
- **말:** "이미 받은 배지라고 하네요. **같은 배지를 두 번 주지 않는 것도 서버가 판정합니다.**
  다른 하천으로 가볼게요."

### 6-1. 카메라 미션 — 리허설에서 뺄지 결정하는 기준

카메라 미션은 **실기기에서 한 번도 돌려본 적이 없습니다.** 넣고 싶다면 아래 기준으로 판단하세요.

**리허설에서 다음 중 하나라도 걸리면 즉시 뺍니다. 고치려 하지 마세요.**

- [ ] 실제 발표에 쓸 기기·브라우저에서 **연속 2회 성공**하지 못했다
- [ ] 촬영에서 업로드 완료까지 **5초를 넘긴 적이 있다** (무대에서 5초는 매우 깁니다)
- [ ] 선택창을 취소했을 때 **화면이 어떻게 되는지 직접 확인하지 않았다**
- [ ] 발표가 **행사장 와이파이**에 의존한다 (이미지 업로드는 대역폭을 씁니다)
- [ ] 발표 시간이 **5분 이하**다 (실패 시 복구할 시간이 없습니다)

**판단이 서지 않으면 빼세요.** 카메라 미션이 주는 것은 "사진을 찍었다"는 장면 하나지만,
실패했을 때 잃는 것은 **그 뒤 대본 전체의 리듬**입니다. 교환비가 나쁩니다.

그리고 빼더라도 **말로는 반드시 언급하세요** — 오히려 점수가 됩니다:

> "사진 미션은 파이프라인까지 만들어 뒀습니다. 촬영하면 **업로드 전에 브라우저에서 EXIF를
> 통째로 지웁니다** — 사진 파일에 박힌 GPS 좌표가 서버로 넘어가면, 체크인에서 좌표를 안 받기로 한
> 설계가 사진으로 되살아나거든요. 다만 **실기기에서 검증하지 못해서 오늘 시연에는 넣지 않았습니다.**"

| 하천 | 미션 | 퀴즈 | 반경 | 배지 이름 | 시연 난이도 |
|---|---|---|---|---|---|
| 수영강 | 없음 | 1 | 1500m | 경상좌수영 수군 | **가장 안전** (퀴즈 1개로 배지까지) |
| 부전천 | 없음 | 1 | 1000m | 복개천 비밀 탐정 | **가장 안전** |
| 온천천 | 수달 탭 | 1 | 1500m | 수달 파파라치 | 안전 (배포본 기준) · **가장 보기 좋음** |
| 동천 | 쓰레기 3개 | 0 | 1000m | 환경 파수꾼 | 안전 · 사진 단계 없음 |
| 대천천 | 관찰일지 4항목 | 1 | 1200m | 생태 탐험가 | 시간이 걸림 |

> **가장 안전한 배지 획득 경로 = 수영강 또는 부전천.** 퀴즈 한 문항만 맞히면 곧바로 배지입니다.
> 미션 단계가 아예 없어서 실패할 구석이 없습니다. **3분 대본이 무너졌을 때의 최후 카드로 기억해 두세요.**
